# Fichas visuales de perfiles de participación electoral

Esta carpeta contiene las cuatro fichas visuales elaboradas a partir de los resultados del análisis de segmentación de la participación electoral histórica en México.

Las fichas presentan de manera gráfica las características principales de los cuatro perfiles identificados mediante *clustering* (k = 4), utilizando información de los procesos electorales de 2009, 2012, 2015, 2018, 2021 y 2024.

## Contenido de la carpeta

| Archivo | Perfil | Clasificación |
|---|---|---|
| `perfil_1_consolidada.png` | Participación consolidada | Históricamente alta |
| `perfil_2_constante.png` | Participación constante | Históricamente media-alta |
| `perfil_3_intermitente.png` | Participación intermitente | Históricamente media-baja |
| `perfil_4_por_activar.png` | Participación por activar | Históricamente baja |
